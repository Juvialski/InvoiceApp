# Scheduling feature module

`contracts.ts` contains the Phase 2 scheduling domain vocabulary and deterministic validation that can be used by persistence, routing, list/table UI, Frappe Gantt adapters, and later CPM logic.

This module currently does not provide persistence, RLS, routing, or production UI. Those remain Phase 2A implementation work described in `docs/ENGORYX_PHASE_2_PROJECT_SCHEDULING.md`.
